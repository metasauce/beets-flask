# Plugins

Beets-flask runs beets under the hood. Many [beets plugins](https://docs.beets.io/en/latest/plugins/index.html) work out of the box.

Some plugins are integrated into beets-flask itself (art previews, source links, icons in the UI).
These integrations are built on beets-flask's [extension system](../develop/resources/extensions.md), which you can extend with your own providers.
